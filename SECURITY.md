# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability.

Use the repository's private security-advisory reporting feature, or contact the maintainer through the contact method listed in the repository profile. Include affected version, reproduction conditions, impact and any suggested mitigation. Do not include secrets.

## Scope

WebShield is a local policy compiler and controlled activation helper. Reports about policy validation, rendered configuration, bundle verification, privilege boundaries, command dispatch and rollback behavior are in scope.

## Operational note

A fix in WebShield does not replace prompt updates of the operating system, NGINX, PHP-FPM or the protected application.
